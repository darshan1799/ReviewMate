# ReviewMate
AI-powered review management platform that helps businesses manage Google reviews from a single dashboard. Features include AI-generated replies, reusable templates, bulk reply management, Google Maps integration, and review tracking. Built with Next.js and MongoDB for a fast and scalable experience.
